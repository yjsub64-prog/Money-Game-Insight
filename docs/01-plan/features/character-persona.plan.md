# Plan: 캐릭터 페르소나 시스템

> 생성일: 2026-03-01
> 기능명: character-persona
> 상태: Plan

---

## 1. 개요

**목표**: 4가지 캐릭터 페르소나를 선택할 수 있는 시스템을 구축하여, 같은 대본이라도 선택한 페르소나에 따라 완전히 다른 분위기/감정/연출의 영상이 만들어지도록 한다.

**핵심 아이디어**:
- 크레용 기본 화풍을 베이스로 4가지 페르소나 제공
- 페르소나 = 캐릭터 외형 + 성격 + 말투 + 감정 반응 규칙 + 시각 연출 가이드라인
- 동일 대본 → 페르소나별로 다른 구도, 색감, 감정 표현, 캐릭터 반응이 나옴
- 각 페르소나는 "한국 사회의 실제 인물 유형"에서 가져온 리얼한 캐릭터

## 2. 4가지 페르소나 정의

### 페르소나 1: "열혈 팀장"
| 항목 | 설명 |
|------|------|
| **배경** | 20년차 중간관리자. 위로는 임원 눈치, 아래로는 MZ세대 관리하느라 샌드위치 인생 |
| **성격** | 열정적이고 직설적, 회식에서 후배 붙잡고 조언하는 스타일. 진심이 묻어남 |
| **말투** | "내가 해봐서 아는데", 목소리에 힘이 있음, 경험 기반 단언 |
| **외형 (크레용)** | 넥타이 풀어헤친 졸라맨, 소매 걷은 팔, 이마에 땀방울, 굵은 눈썹 |
| **대표 색상** | 진한 남색/빨간 넥타이 포인트 (열정+직장인 느낌) |
| **감정 반응** | 긍정→ 주먹 불끈+눈에 불꽃, 부정→ 책상 내려치며 분노+넥타이 움켜잡음, 중립→ 팔짱 끼고 고개 끄덕 |
| **구도 경향** | STANDARD~MACRO (캐릭터가 화면을 장악, 강한 존재감) |
| **어울리는 콘텐츠** | 직장 생활, 리더십, 자기계발, 현실 조언, 세대 갈등 |

### 페르소나 2: "차분한 교수님"
| 항목 | 설명 |
|------|------|
| **배경** | 대학에서 경영학을 가르치는 50대 교수. 감정보다 근거 중시 |
| **성격** | 논리적이고 차분, "자, 한번 생각해봅시다"로 시작. 동료에게 설명하듯 |
| **말투** | 느린 호흡, 정제된 문장, 감정 절제, 학술적 어조 |
| **외형 (크레용)** | 둥근 안경 쓴 졸라맨, 정돈된 머리, 한 손에 책/포인터, 반듯한 자세 |
| **대표 색상** | 짙은 녹색/갈색 (학문적 권위+차분함) |
| **감정 반응** | 긍정→ 안경 만지며 미소+칠판에 O표시, 부정→ 턱 괴고 심각한 표정+그래프에 빨간 선, 중립→ 칠판 앞에서 설명 포즈 |
| **구도 경향** | STANDARD (캐릭터와 데이터/자료가 균형 있게 공존) |
| **어울리는 콘텐츠** | 경제 분석, 시장 해석, 학술적 설명, 역사/트렌드 분석 |

### 페르소나 3: "솔직한 자영업자"
| 항목 | 설명 |
|------|------|
| **배경** | 식당 10년 운영 후 최근 폐업한 50대 초반. 현장 경험에서 나오는 리얼함 |
| **성격** | 거침없고 솔직, 허세 없이 자기 이야기를 함. 이론보다 실전 |
| **말투** | "이론은 모르겠고요", "현실은 다릅니다", 직설적이고 꾸밈없는 표현 |
| **외형 (크레용)** | 앞치마 두른 졸라맨(또는 벗어둔 앞치마), 피곤한 눈, 투박한 손, 구부정한 어깨 |
| **대표 색상** | 흙색/주황색 (현장감+서민적 따뜻함) |
| **감정 반응** | 긍정→ 엄지척+씩 웃음, 부정→ 한숨+머리 긁적+빈 가게 배경, 중립→ 팔짱 끼고 "글쎄요" 표정 |
| **구도 경향** | MICRO~STANDARD (현실 세계가 크고, 그 안에서 버티는 캐릭터) |
| **어울리는 콘텐츠** | 자영업, 소상공인, 물가/경기, 현실 경제, 창업/폐업 |

### 페르소나 4: "걱정 많은 학부모"
| 항목 | 설명 |
|------|------|
| **배경** | 중학생 자녀를 둔 40대. 아이 진로 때문에 AI를 공부하기 시작 |
| **성격** | 조심스럽고 질문이 많음. 불안하지만 배우려는 의지가 있음 |
| **말투** | "우리 애는 뭘 시켜야 하나", "나는 이제 늦은 건 아닌가", 걱정 섞인 질문형 |
| **외형 (크레용)** | 살짝 웅크린 졸라맨, 양손 모음, 물음표가 주변에 떠다님, 부드러운 곡선 |
| **대표 색상** | 연보라/연분홍 (불안+부드러움+모성/부성) |
| **감정 반응** | 긍정→ 두 손 모아 안도+작은 미소, 부정→ 눈 크게 뜨고 불안+물음표 폭발, 중립→ 고개 갸우뚱+손가락 입에 대고 생각 |
| **구도 경향** | MICRO (세상이 크고 복잡해 보이고, 캐릭터는 작고 불안한 느낌) |
| **어울리는 콘텐츠** | AI/미래 기술, 교육, 진로, 육아, 부동산(내 집 마련) |

## 3. 시스템 동작 원리

```
[사용자] 페르소나 선택 (열혈 팀장/차분한 교수님/솔직한 자영업자/걱정 많은 학부모)
    ↓
[스크립트 생성] 페르소나 성격이 반영된 시각화 지시
    ↓
[프롬프트 엔진] 페르소나별 감정 반응 규칙 + 구도 + 색감 적용
    ↓
[이미지 생성] 같은 대본이라도 다른 분위기의 이미지 출력
```

### 예시: "삼성전자 주가가 10% 급등했다"

| 페르소나 | 시각화 결과 |
|---------|-----------|
| **열혈 팀장** | 넥타이 풀어헤친 팀장이 주먹 불끈+눈에 불꽃, "삼성" 큰 텍스트+폭등 차트, 진한 남색 배경에 빨간 화살표 |
| **차분한 교수님** | 안경 쓴 교수가 칠판 앞에서 차트 가리키며 설명, 상승 그래프+분석 수치, 녹색/갈색 차분한 배경 |
| **솔직한 자영업자** | 앞치마 벗어둔 자영업자가 폰 보며 "진짜?" 표정, 작은 가게 안에서 삼성 뉴스 확인, 흙색 따뜻한 배경 |
| **걱정 많은 학부모** | 웅크린 학부모가 "우리 애 삼성 시켜야 하나?" 물음표 떠다님, 거대한 삼성 빌딩 아래 작은 캐릭터, 연보라 배경 |

## 4. prompts.ts 감정 반응 규칙 (핵심 설계)

### 4-1. 감정(sentiment)별 반응 매트릭스

| | POSITIVE | NEGATIVE | NEUTRAL |
|---|---------|----------|---------|
| **열혈 팀장** | 주먹 불끈, 눈에 불꽃, 에너지 폭발 배경 | 책상 내려치기, 넥타이 움켜잡기, 어두운 사무실 | 팔짱+고개 끄덕, 회의실 배경 |
| **차분한 교수님** | 안경 만지며 미소, 칠판에 O, 밝은 강의실 | 턱 괴고 심각, 그래프에 빨간 하락선 | 포인터로 자료 가리킴, 차분한 배경 |
| **솔직한 자영업자** | 엄지척+씩 웃음, 가게에 손님 가득 | 한숨+빈 가게, 셔터 내린 배경 | 팔짱+"글쎄요" 표정, 가게 카운터 |
| **걱정 많은 학부모** | 두 손 모아 안도+작은 미소, 아이 옆에서 | 눈 크게+물음표 폭발, 불안한 배경 | 손가락 입에 대고 생각, 물음표 둥둥 |

### 4-2. 구도 오버라이드 규칙

기존 `composition_type`에 페르소나 보정을 적용:

```
열혈 팀장:   MICRO→STANDARD, STANDARD→STANDARD, MACRO→MACRO   (존재감 강화)
차분한 교수님: MICRO→STANDARD, STANDARD→STANDARD, MACRO→STANDARD (항상 균형)
솔직한 자영업자: MICRO→MICRO, STANDARD→MICRO, MACRO→STANDARD  (현실 속 작은 존재)
걱정 많은 학부모: MICRO→MICRO, STANDARD→MICRO, MACRO→STANDARD (세상이 크고 불안)
```

### 4-3. 색상 팔레트 규칙

| 페르소나 | 기본 배경색 | 긍정 강조 | 부정 강조 | 포인트 |
|---------|-----------|----------|----------|--------|
| 열혈 팀장 | 진한 남색 | 빨강/금색 | 어두운 회색 | 빨간 넥타이 |
| 차분한 교수님 | 짙은 녹색 | 밝은 초록 | 차분한 빨강 | 안경 하이라이트 |
| 솔직한 자영업자 | 흙색/베이지 | 따뜻한 주황 | 칙칙한 회색 | 앞치마 색 |
| 걱정 많은 학부모 | 연보라/연분홍 | 부드러운 하늘색 | 진한 보라 | 물음표 색상 |

## 7. 기술적 고려사항

### 기존 시스템과의 호환
- 페르소나 미선택 시 = 기존 방식 그대로 동작 (기본 졸라맨)
- 기존 `VAR_BASE_CHAR` → 페르소나별 캐릭터 설명으로 오버라이드
- 기존 `composition_type` → 페르소나 성격에 따라 가중치 조정 (완전 대체X, 보정O)

### prompts.ts 확장 전략
- `getPersonaEmotionGuide(personaId, sentiment)` → 감정별 시각 연출 가이드 반환
- `getPersonaCharacterPrompt(personaId)` → 페르소나별 캐릭터 외형 프롬프트 반환
- `getPersonaColorPalette(personaId, sentiment)` → 페르소나+감정별 색상 팔레트 반환
- `getPersonaCompositionOverride(personaId, originalType)` → 구도 보정값 반환
- `getFinalVisualPrompt()`에 `personaId` 파라미터 추가

### 저장 및 복원
- 선택된 페르소나는 `localStorage`에 저장 (기본값: 없음/기존 모드)
- `SavedProject`에 `personaId` 필드 추가 → 프로젝트 불러올 때 복원

## 8. 비기능 요구사항

- 페르소나 선택 UI는 직관적인 카드형 디자인 (캐릭터 아이콘 + 이름 + 한줄 성격 설명)
- 페르소나 선택 시 해당 캐릭터의 상세 성격/말투/배경 설명이 표시됨
- 기존 기능(화풍 선택, 참조 이미지 등)과 충돌 없이 공존
- 크레용 화풍이 기본 베이스, 다른 화풍 선택 시에도 페르소나 성격은 유지

## 9. 성공 기준

- [ ] 4개 페르소나(열혈 팀장, 차분한 교수님, 솔직한 자영업자, 걱정 많은 학부모) 중 하나를 선택할 수 있다
- [ ] 선택 시 캐릭터의 성격, 말투, 배경 설명이 표시된다
- [ ] 같은 대본으로 다른 페르소나를 선택하면 다른 분위기의 이미지가 나온다
- [ ] prompts.ts에 페르소나별 감정/구도/색감 규칙이 정의되어 있다
- [ ] 페르소나 미선택 시 기존 방식 그대로 동작한다
- [ ] 페르소나별 캐릭터 외형이 크레용 화풍으로 일관성 있게 표현된다
